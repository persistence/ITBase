# 谓词

职责：在一次数据读写之前，用当前用户的主体事实和 [授权](01-授权.md)，得出该实体、该动作的谓词。数据读写模块把读谓词编译成参数化条件，把写谓词用于拒绝字段和行。

不负责：SQL 文本。本模块交给数据读写的是下面第 2 节的结构。列名只由数据读写按目录映射。

依赖：主体事实的形状见 [组织角色](../用户与组织/03-组织角色.md)。部门下级通过只读闭包表得出。闭包的维护仍在部门模块。

## 1. 允许的部门

对当前用户、当前角色、当前这条授权，先得出部门 id 集合。用户状态不是 `active` 时，集合为空，不必再读授权。

| 角色上的范围 | `dept_self` | `dept_tree` |
|---|---|---|
| 组织范围（绑定的部门为空） | 主体事实里的 `deptIds` | 主体事实里的 `deptIdsWithDescendants` |
| 部门范围 | 该角色未结束绑定上的部门 id | 这些部门 id 各自的下级，含自身 |

一名用户持有同一角色的多条部门绑定，这些部门取并集。`scope = all` 的授权不计算部门集合。

`dept_leader` 是部门范围角色。只使用它绑定上的部门，不用这名用户因任职而进入的其他部门。组织范围的自定义角色则使用任职部门，不使用 `dept_leader` 的绑定部门。

## 2. 交给数据读写的结构

同一实体、同一动作下，当前用户每一个仍然有效的角色若有授权，就产生一个分支。全部分支取或。

```json
{
  "action": "read",
  "effect": "allow",
  "or": [
    { "kind": "all" },
    { "kind": "in", "field": "dept", "ids": ["10", "11"] }
  ]
}
```

没有任何分支时，`effect` 为 `deny`，`or` 为空数组。`ids` 是十进制字符串。空的 `in` 表示这一支匹配不到行，不能把它省掉后变成全表。

`kind = all` 出现在任一分支时，读路径不加行条件。数据读写仍要加上软删除条件，以及用户自己的筛选。最终 `WHERE` 保持 [数据读写](../数据模型/04-数据读写.md) 已写明的顺序：权限谓词，然后软删除，然后用户 `filter`。

一次请求里同一用户、同一实体只编译一次。写入图上的每张实体按自己的动作另算。子行 `create` 看子实体的 `create`，不继承父实体的 `update`。

## 3. 读

列表和详情在读之前取 `action = read` 的谓词。

- 列表把谓词加到主查询。`expand` 加载目标行时，对目标实体再取一次 `read` 谓词。目标行不在范围内则该导航为 `null`，不让整页 404。
- 按 id 读取时，谓词与主键同时成立才返回行。不成立返回 404，与行不存在相同。
- 变更历史与该行详情使用同一读谓词。读不到行就不能读它的历史。

用户 `filter` 里的 `or` 只作用在权限谓词已经留下的行上。

## 4. 写

写之前先看动作，再看行，再看字段。未知字段由数据读写返回 400，不到这里。

| 动作 | 行如何判定 |
|---|---|
| `create` | 没有 `create` 分支则 403。`in` 分支要求请求体里的 `dept_field` 落在 `ids` 中，否则 403。`all` 分支不检查该字段 |
| `update` | 先用 `read` 谓词确认行可见，不可见为 404。再要求有 `update` 分支，且若修改了 `dept_field`，新值要落在该分支的 `ids` 中，否则 403 |
| `delete` | 行不可见为 404。可见但没有 `delete` 分支为 403 |

第一期有相应动作即可写全部 `active` 字段和导航。已知字段不会因为「只授了实体、没授字段」而 403。

判定失败不进入 CEL，也不写变更历史。

解释器的 `Read`、`Query`、`Create`、`Update`、`Delete` 使用同一结构和同一主体。主体是宿主注入的 `Actor`，领域函数不能改这个主体。

## 5. 本模块完成标准

- 只有下级部门授权时，列表不返回同级部门的行。按同级部门那一行的 id 读取返回 404。
- 筛选 `{ "or": [ { "field": "dept", "op": "eq", "value": "<同级部门>" } ] }` 的结果仍为空。
- 同一用户既有 `all` 的 `read`，又有某部门的 `read` 时，列表包含范围外的行。
- 新建时部门字段不在允许集合里返回 403，不插入行。
- 写入图同时新建父行和子行时，子实体没有 `create` 则整单回滚，父行也不留下。
